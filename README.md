💼 Telegram-бот «Портфолио Разработчика» 🚀Персональный Telegram-бот для удобного сохранения, управления и презентации собственных проектов и стек-навыков. Бот позволяет структурированно вести учёт всех разработок, отслеживать их текущие статусы, привязывать используемые технологии и делиться ими!✨ Основные возможности➕ Управление проектами: Удобный пошаговый процесс добавления новых проектов (название, описание, ссылка, статус).🏷 Статусы и Навыки: Возможность задавать статус выполнения проекта и привязывать к нему используемые технологии/навыки.✏️ Гибкое редактирование: Обновление названия, описания, ссылки или статуса проекта в любое время.📱 Интерактивный UI: Удобные клавиатуры (Inline и Reply), автоскрытие меню после выбора и наглядные карточки проектов.🗑 Управление базой: Удаление устаревших или неактуальных проектов.🛠 ТехнологииЯзык программирования: Python 3.9+Библиотека Telegram API: pyTelegramBotAPI (telebot)База данных: SQLite 3📖 Список команд ботаКомандаОписание/start🤖 Запустить бота и получить приветственное сообщение/info📖 Показать справку по всем командам и возможностям/new_project➕ Начать процесс добавления нового проекта/projects📂 Посмотреть список всех сохранённых проектов/update_projects⚙️ Редактировать атрибуты существующего проекта/skills🛠 Привязать навык/технологию к проекту/delete🗑 Удалить проект из базы данных🎨 Скриншоты и Интерфейс(Добавьте сюда скриншоты работы вашего бота)Просмотр проектовДобавление навыка[ Вставьте скриншот ][ Вставьте скриншот ]📝 ЛицензияПроект распространяется под лицензией MIT.
